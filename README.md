# 混沌生涯职业体验舱 Demo

这是一个纯静态、可部署到 GitHub Pages 的演示版本，用来表达“大学生混沌生涯职业体验模型游戏”的核心交互。

## 已实现

- 注册体验弹窗，注册后生成专属量子种子
- 当下状态录入：年龄、容貌、住房、收入、幸福感、身体状态、财富、婚姻、家庭、子女、学习成绩
- 生涯阶段切换：小学、初中、高中、大学、研究生、恋爱、工作
- 360 VR 全景窗口的模拟视觉区域
- 未来加速轴：一键加速到未来年份
- 未来状态快照：年龄、住房、收入、幸福感、身体状态、财富、婚姻、子女、学习/职业
- 混沌生涯机器人：根据状态、阶段、年份和决策给出生涯建议
- 决策按钮：学习投入、社交拓展、健康优先、创业冒险，会影响未来模拟结果

## 本地预览

Windows 上可以直接双击：

```text
start-demo.bat
```

或在命令行运行：

```bash
node server.mjs
```

打开：

```text
http://127.0.0.1:4173
```

也可以直接打开 `index.html` 查看静态页面。

## GitHub Pages 部署

1. 新建一个 GitHub 仓库，例如 `chaos-career-demo`。
2. 将本目录所有文件提交到仓库根目录。
3. 在仓库设置里打开 `Settings -> Pages`。
4. Source 选择 `Deploy from a branch`，Branch 选择 `main`，目录选择 `/root`。
5. 保存后等待 GitHub Pages 构建完成。

部署完成后，页面地址通常是：

```text
https://你的用户名.github.io/chaos-career-demo/
```
